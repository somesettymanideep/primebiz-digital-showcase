# PRIMEBIZPRO Website Plan

## Outcome
Build a complete, responsive seven-page PRIMEBIZPRO website using the supplied logo, page briefs, brand palette, and product concepts.

## Work
- Create Home, About Us, Our Solutions, Industries, Technology & Innovation, Why PRIMEBIZPRO, and Contact Us pages with working navigation and page-specific search metadata.
- Add shared navigation with a six-solution mega menu, mobile menu, calls to action, footer, custom not-found page, back-to-top, and a contact shortcut.
- Establish the supplied navy, orange, blue, and graphite palette as global design tokens; add original, relevant imagery and restrained motion with reduced-motion support.
- Keep all product concepts explicitly envisioned, not operational; use placeholders instead of invented contact details, testimonials, statistics, or capabilities.
- Build a validated, accessible enquiry form that stores submissions in Lovable Cloud; do not claim email delivery unless a verified sending setup exists. A direct WhatsApp destination will remain pending a verified number, so the floating contact shortcut will open Contact Us meanwhile.

## Technical details
- Use the existing TanStack Start routes and shared React/CSS patterns; add per-page titles, descriptions, Open Graph, Twitter card, semantic headings, and keyboard-accessible interactions.
- Validate contact data on both sides and store it in a protected submissions table with no anonymous read access. Verify navigation, form validation/submission, and desktop/mobile layouts before completion.
